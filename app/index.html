Welcome to Scalable Web App!

A hands-on AWS cloud project demonstrating web hosting, load balancing, automated instance provisioning, and infrastructure scalability.

● Application Responding

Project Overview

Amazon EC2

Hosts the web application on Amazon Linux 2023 using Apache HTTP Server.

Application Load Balancer

Receives HTTP traffic and forwards requests to registered application instances.

Auto Scaling Group

Manages EC2 instance capacity according to the configured minimum, desired, and maximum capacity.

Target Group

Registers EC2 instances and checks application health using HTTP requests.

Implementation Highlights

  • Configured an Application Load Balancer with an HTTP listener.
  • Configured target group health checks on port 80.
  • Used a launch template to define EC2 instance settings.
  • Automated Apache installation and web page creation with user data.
  • Configured an Auto Scaling Group with desired capacity 1, minimum 1, and maximum 2.
  • Used IAM and AWS Systems Manager for managed instance access.
  • Verified that the website was accessible through the ALB DNS name.
